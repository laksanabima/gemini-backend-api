Generative AI untuk Layanan RSUD Brebes

Layanan backend AI yang menyediakan kemampuan pemrosesan teks, gambar, dokumen, dan audio dalam satu REST API.

SPECIFICATION REST / JSON
BASE PATH: /generate-[action]
MODALITIES: 4 TYPES
MAX PAYLOAD: 20 MB
AUTH: HEADER API-KEY
[ SECURITY PROTOCOL 01 ]
!

Autentikasi Diperlukan

Semua endpoint API wajib menyertakan header x-api-key yang valid.
Permintaan tanpa header tersebut akan menerima respons 401 Unauthorized.

x-api-key: kunci_rahasia_anda [ HEADER ]

// Hubungi IT RSUD Brebes untuk mendapatkan kunci API Anda.

[!]

Integrasi Pengembangan untuk Website

API Key bersifat rahasia. Simpan hanya di sisi server/backend, jangan menaruhnya di kode frontend atau repositori, dan jangan dibagikan ke pihak lain.

// CATALOGUE

Daftar Endpoint API

BASE URL: https://genai.rsudbrebes.id
NO. 01 // TEXT [ POST ]

/generate-text

Menghasilkan jawaban dari sebuah prompt teks — cocok untuk tanya jawab, penyusunan draf, dan ringkasan singkat.

CONTENT-TYPE: application/json
PAYLOAD FIELDS: prompt, system*
NO. 02 // VISION [ POST ]

/generate-from-image

Menganalisis gambar dan menjawab berdasarkan isinya, misalnya pemeriksaan visual atau ekstraksi informasi.

CONTENT-TYPE: multipart/form-data
PAYLOAD FIELDS: image, prompt, system*
SUPPORTED: jpeg, png, webp, heic, heif
NO. 03 // DOCS [ POST ]

/generate-from-document

Membaca dokumen dan menghasilkan ringkasan atau jawaban atas pertanyaan seputar isinya secara otomatis.

CONTENT-TYPE: multipart/form-data
PAYLOAD FIELDS: document, prompt, system*
SUPPORTED: pdf, txt
NO. 04 // AUDIO [ POST ]

/generate-from-audio

Melakukan transkripsi dan memahami rekaman audio, misalnya notulen rapat atau catatan suara.

CONTENT-TYPE: multipart/form-data
PAYLOAD FIELDS: audio, prompt, system*
SUPPORTED: mp3, wav, aiff, aac, ogg, flac

* Field system bersifat opsional dan mengatur peran serta batasan topik jawaban model.

// CODE EXAMPLES

Contoh Integrasi API

C:\GENAI\REQUEST_CURL.BAT HTTP/1.1

// Example POST Request using cURL

curl -X POST https://genai.rsudbrebes.id/generate-text \
  -H "x-api-key: kunci_rahasia_anda" \
  -H "Content-Type: application/json" \
  -d '{
    "system": "Kamu adalah asisten dokter AI yang ahli dan ramah...",
    "prompt": "Jelaskan langkah pencegahan demam berdarah."
  }'
RESPONSE_PAYLOAD.JSON 200 OK

// JSON Output Response

{
  "result": "Demam berdarah dapat dicegah dengan..."
}
// STATUS MATRIX

Kode Status HTTP

[ CODE ] [ KETERANGAN ]
200 OK Permintaan berhasil diproses.
400 BAD REQUEST File wajib belum dikirim atau tipe file tidak didukung.
401 UNAUTH Header x-api-key tidak ada atau tidak valid.
413 OVERSIZE Ukuran file melebihi batas 20MB.
500 SERVER ERR Terjadi kesalahan saat memproses permintaan ke model AI.
